# Pablo Sabater — portfolio site

**Version 1.0** — first version, with placeholder images.

Personal portfolio of Pablo Sabater, Electrical and Computer Engineering (Honors) student at Northeastern University. Live at **https://pablosabaterlp.github.io**.

Built with plain HTML, CSS, and JavaScript (no frameworks or build step) and hosted on GitHub Pages.

## Editing

- Page text, in English and Spanish: `js/i18n.js`
- Links (site URL, email, LinkedIn, GitHub): `js/config.js`
- QR codes: re-run `python scripts/make_qr.py` after changing links (see `scripts/README.md`)
